# Restaurant Manager Pro

**Restaurant Manager Pro** es una solución integral diseñada para optimizar la gestión operativa de restaurantes. Enfocado en la **agilidad**, el sistema permite la toma de pedidos rápida desde dispositivos móviles (tablets), la gestión visual de mesas en tiempo real y la generación automatizada de reportes de ventas diarios para una toma de decisiones informada.

## 🚀 Características Principales

*   **Toma de Pedidos Ágil:** Interfaz optimizada para tablets que reduce el tiempo de atención al cliente.
*   **Gestión de Mesas en Tiempo Real:** Visualización y control del estado de las mesas (disponibles, ocupadas, reservadas).
*   **Reportes de Ventas:** Generación de reportes diarios para un seguimiento financiero preciso.
*   **Control de Inventario:** Gestión centralizada de productos y catálogo.
*   **Seguridad:** Sistema de autenticación y control de acceso basado en roles (RBAC).

## 🛠 Stack Tecnológico

El proyecto utiliza un stack moderno para garantizar rendimiento, escalabilidad y mantenibilidad:

### Frontend
*   **React** (con Vite)
*   **TypeScript**
*   **Tailwind CSS**
*   **Redux Toolkit**

### Backend
*   **Node.js**
*   **Express**
*   **TypeScript**

### Base de Datos
*   **MongoDB Atlas** (Base de datos NoSQL en la nube)

## 📋 Instrucciones de Instalación

1.  **Clonar el repositorio:**
    ```bash
    git clone [TU_URL_DEL_REPOSITORIO]
    cd sistema-de-restaurante
    ```

2.  **Configurar Backend:**
    ```bash
    cd backend
    npm install
    # Configurar variables de entorno (.env) con tu URI de MongoDB Atlas
    npm run dev
    ```

3.  **Configurar Frontend:**
    ```bash
    cd ../frontend
    npm install
    npm run dev
    ```
